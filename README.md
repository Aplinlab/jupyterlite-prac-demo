# JupyterLite practical notes: feature demo (prototype)

Built JupyterLite site for a convenor demo: one task from a neurophysiology practical (membrane potentials, Table 1) showing tablet-friendly forms, quizzes, save/resume, reset, class data and an AI tutor.

**Prototype only. Not for students.** Placeholder content and made-up data.

- Open the site: https://aplinlab.github.io/jupyterlite-prac-demo/
- Class data needs a local class-data server on the presenter's laptop (`http://localhost:8765`).
- The AI tutor needs an API key typed into the browser at runtime. No key is stored here.

This repo holds generated files only. The source lives in a separate repository.
